# Task Manager 📝

Proyecto escolar/personal de Task Manager hecho con Node.js (Express), PostgreSQL y app móvil con Flutter. Incluye login con JWT y refresh tokens, además de todas las pruebas que pedía la guía.

## 🚀 Cómo correr el proyecto rápido

**Backend:**
```bash
cd backend
npm install
npm test
npm start
```

**App Móvil (Flutter):**
```bash
cd mobile
flutter pub get
flutter test
flutter run
```
